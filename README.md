# Maps for the Trąbczyn and Zagórów edition

The image tiles of the old maps used by the edition at
https://takaji10.github.io/triebenfeld-letters/ (its repository:
https://github.com/takaji10/triebenfeld-letters). Each map is a folder of
IIIF level-0 static tiles with its `info.json`, and a georeference
annotation (`georef.json`) that places it on the ground.

The maps, their descriptions and the marks on them are kept in the edition's
repository (`reference/maps.yml`, `maps/<map>/`); this repository holds only
what the browser loads. It is made by the edition's scripts
(`pipeline/maps/`), not by hand. How a map is added:
`docs/ADDING_A_MAP.md` in the edition's repository.
